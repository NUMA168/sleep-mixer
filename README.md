# 眠りの音ミキサー

好きな環境音を重ねて、スライダーで音量を調整できる睡眠用ミキサー。

- `index.html` … ページ本体
- `sounds/` … 音源（mp3）

## 公開手順（GitHub Pages）
1. GitHubで新しい **Public** リポジトリを作る（例: `sleep-mixer`）
2. このフォルダの中身（`index.html`・`sounds`・`.nojekyll`・`README.md`）をすべてアップロード
3. リポジトリの **Settings → Pages → Build and deployment** で
   Source: *Deploy from a branch* / Branch: *main* / */(root)* を選んで Save
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける
